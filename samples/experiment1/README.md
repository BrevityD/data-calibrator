## 实验设置

这里暂时涉及三个数据集，它们有一定的相近，但又有相当的距离：

- math：主要使用 `lighteval` 的 `MATH-Hard` 数据集。不能使用DAPO、AIME的主要原因是没有解题过程，不适合SFT；不使用GSM8k等的主要原因是已经被刷爆了。
- code：主要使用 `bigcodebench`。实际上我一直有这样的考虑：用测试集直接进行训练可能是更好的选择，因为我们可以直接得到这样的结论：目前的主流模型可能在训练集上过拟合了，但肯定没有在测试集上直接进行过任何训练。不用SWE-bench的原因是任务过于复杂，不方便讨论很多东西；不使用mbpp的原因是被刷爆了。
- logic：主要使用 `prontoqa`，一个主要使用三段论推理的数据集。问题其实在于这个数据集比较难评测，我计划对不同的chains进行清楚的划分，然后用ROUGE等估算相似度进行步骤匹配。
