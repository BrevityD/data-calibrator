# variational_geodesic.py 实现思路

## 目标

求解从给定起点到竖直线 $x = x_{\text{target}}$ 的最短测地线。终点的 $x$ 坐标固定为 $x_{\text{target}}$，$y$ 坐标由优化自动确定。通过最小化离散能量，自动满足横截性条件（终点切向量与直线在度规意义下正交）。

## 数学背景

在黎曼流形上，两点间的测地线是使能量泛函取极值的曲线。当终点不是一个固定点而是一条子流形（这里是竖直线 $x = x_{\text{target}}$）时，最短路径除了满足测地线方程外，还需满足横截性条件：终点处的切向量必须与该子流形在度规意义下正交。

本程序的关键洞察是：将终点 $y$ 坐标设为自由变量并最小化离散能量，横截性条件作为自然边界条件自动满足，无需显式施加。

## 核心思路

### 1. 离散变分法求测地线（`variational_geodesic_to_line`）

将路径离散为 $N+1$ 个节点 $q_0, q_1, \dots, q_N$，其中：
- $q_0$ = 起点（固定）
- $q_N = (x_{\text{target}},\; y_{\text{free}})$，$x$ 固定，$y$ 自由
- $q_1, \dots, q_{N-1}$ 为内部自由节点

定义离散能量：

$$E = \sum_{i=0}^{N-1} \Delta q_i^T \, G(m_i) \, \Delta q_i$$

其中 $\Delta q_i = q_{i+1} - q_i$，$m_i = \frac{1}{2}(q_i + q_{i+1})$ 为中点，$G$ 为该点的度规张量（由神经网络 `metric_tensor_xy_batch` 提供）。

最小化该能量等价于求测地线，同时终点 $y$ 自由使得横截性条件自然满足。

**初始化策略：** 默认将起点到 $(x_{\text{target}}, y_{\text{init}})$ 的直线等分为 $N+1$ 个点。也可通过 `init_path` 参数传入外部初始路径（例如粗搜索的结果），此时跳过直线插值。

**优化器选择：** 使用 PyTorch 的 L-BFGS 优化器，配合 strong Wolfe line search。L-BFGS 利用二阶曲率信息，对这类光滑能量函数收敛速度远快于一阶方法。每次外层迭代内部最多执行 20 步 line search（`max_iter=20`）。

**收敛判据：** 同时要求两个条件满足才判定收敛：
1. 能量相对变化 $|E_{k-1} - E_k| / (|E_k| + 10^{-12}) < \text{tol}$（默认 $10^{-8}$）
2. 梯度范数 $\|\nabla E\| < \text{grad\_tol}$（默认 $10^{-6}$）
3. 迭代次数 > 10（避免初期偶然满足）

**参数安全网：** 每步优化后对参数执行 `clamp_(eps, 1-eps)`，防止坐标越界。这是硬约束的最后防线，正常情况下对数障碍已经将路径保持在可行域内。

### 2. 对数障碍约束

坐标需限制在 $(\epsilon, 1-\epsilon)$ 范围内（$\epsilon = 10^{-4}$）。采用对数障碍函数（interior point method 的核心思想）：

$$E_{\text{barrier}} = -\mu \sum_{c \in \text{free}} \left[\log(c - \epsilon) + \log(1 - \epsilon - c)\right]$$

其中求和遍历所有自由坐标（内部节点的 $x, y$ 以及终点的 $y$）。当坐标趋近边界时，$-\log$ 项趋向 $+\infty$，形成软壁效应。

**退火策略：** $\mu$ 每隔 `barrier_anneal_every` 步（默认 50）乘以 `barrier_anneal`（默认 0.5），即指数衰减。这使得：
- 早期 $\mu$ 较大，障碍项主导，路径被强力约束在可行域内部
- 后期 $\mu \to 0$，障碍项影响消失，优化结果逼近真实测地线

精化阶段直接设 $\mu = 0$，因为粗搜索已将路径引导到远离边界的位置。

### 3. 两阶段多起点搜索

为避免陷入局部最优，采用两阶段策略：

**阶段 1 — 批量粗搜索（`batch_coarse_search`）**
- 在 $y \in [0.05, 0.95]$ 上均匀取 $K$（默认 12）个候选终点
- 每条路径初始化为起点到 $(x_{\text{target}}, y_k)$ 的直线等分
- 将 $K$ 条路径的参数打包为 $(K, n_{\text{free}})$ 矩阵，用 Adam 优化器（lr=0.01）并行优化
- 关键优化：所有 $K \times N$ 个中点一次性送入 NN 计算度规张量，共享 forward pass，避免 $K$ 次独立推理
- 收敛判据：所有 $K$ 条路径的能量相对变化均 $< 10^{-7}$
- 按弧长排序，筛选出 top-$k$ 候选

**阶段 2 — L-BFGS 精化（`variational_geodesic_to_line`）**
- 将粗搜索的 top-$k$（默认 3）路径通过线性插值重采样到 `refine_N`（默认 200）个节点，提高空间分辨率
- 用 L-BFGS（strong Wolfe line search）逐条精化，收敛精度更高
- 关闭障碍项（$\mu = 0$），依赖粗搜索已将路径引导到可行域内部
- 取弧长最短者为最终结果

**为什么分两阶段：** Adam 适合并行处理多条路径的粗搜索（一阶方法，内存友好，支持 mini-batch），但收敛精度有限；L-BFGS 收敛精度高但不支持批量优化。两者互补。

### 4. 横截性检验（`check_transversality`）

验证终点切向量 $\dot{q}_N$ 与直线切向量 $e_y = (0,1)$ 在度规意义下的正交性：

$$\cos\theta = \frac{\dot{q}_N^T \, G \, e_y}{\|\dot{q}_N\|_G \, \|e_y\|_G}$$

其中 $\dot{q}_N$ 取最后一段差分 $q_N - q_{N-1}$ 近似，$G$ 在终点处求值。该值越接近 0，说明横截性条件满足越好。实际运行中，经过精化后该值通常在 $10^{-3}$ 量级以下。

### 5. 弧长计算（`compute_variational_arc_length`）

$$L = \sum_{i=0}^{N-1} \sqrt{\Delta q_i^T \, G(m_i) \, \Delta q_i}$$

注意弧长 $L$ 与能量 $E$ 的区别：能量是各段 $ds^2$ 之和，弧长是各段 $ds$ 之和。由 Cauchy-Schwarz 不等式，$L^2 \leq N \cdot E$，等号在路径等速参数化时成立（即测地线）。因此弧长是更直接的"距离"度量，用于比较不同候选路径。

实现上使用 `np.einsum` 批量计算，对 $ds^2 < 0$ 的数值噪声段做 mask 过滤。

## 自由变量编码

总共 $2(N-1) + 1$ 个标量，存储为一维 `torch.Tensor`：
- `params[2*(i-1)]` 和 `params[2*(i-1)+1]`：第 $i$ 个内部节点的 $x, y$ 坐标（$i = 1, \dots, N-1$）
- `params[-1]`：终点 $y$ 坐标

`build_path(params)` 函数将这个一维向量重组为 $(N+1, 2)$ 的完整路径，起点 $q_0$ 固定拼接在前，终点 $x$ 固定为 $x_{\text{target}}$。

## 依赖

从 `draw_geo.py` 复用以下基础设施：
- `metric_tensor_xy_batch`：批量计算度规张量 $G(x, y)$，输入 $(B, 2)$，输出 $(B, 2, 2)$
- `metric_mat`：单点度规张量
- `compute_logdet_grid`：计算 $\log\det G$ 的网格数据（用于热力图）
- `draw_metric_ellipses`：绘制度规椭圆
- `device`, `dtype`：PyTorch 设备和数据类型配置

## 可视化（`plot_variational_geodesic_to_line`）

生成的图包含以下元素：
- 背景：$\log\det G$ 热力图（反映度规的各向异性分布）
- 白色椭圆：各点处的度规椭圆（椭圆越扁表示各向异性越强）
- 青色虚线：目标直线 $x = x_{\text{target}}$
- 灰色细线：所有粗搜索候选路径
- 红色粗线：最优测地线
- 青色/黄色圆点：起点/终点
- 标题：能量、弧长、横截性指标

## 输出文件

- `.png`：可视化图（dpi=220）
- `_log.json`：完整日志，包含起终点、能量、弧长、横截性指标、收敛信息、能量历史曲线、所有候选摘要

## 默认运行参数

主程序默认配置：
- 起点 $(0.9, 0.9)$，目标线 $x = 0.2$
- 粗搜索：$K = 12$ 个候选，$N = 100$
- 精化：top-3，$N_{\text{refine}} = 200$，最多 500 次迭代
