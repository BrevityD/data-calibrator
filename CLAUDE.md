# Standards

## Code Style

- Code style should be kept as consistent as possible with the requirements below.

### Hyperparameter Config 

- All hyperparameters should be logged to `wandb`.
- Hyperparameters should be managed using `argparse`.

### Output Directory

All artifacts generated by runnable scripts should be saved under a dedicated result directory instead of the source code directory.

Use the following convention:

`fit_metric/result/<script_name>/<timestamp>/`

Where:
- `<script_name>` is the script filename without the `.py` suffix
- `<timestamp>` is the run timestamp, for example: `2026-03-25_14-30-00`

This applies to all generated files, including but not limited to:
- figures (`.png`, `.jpg`, `.pdf`)
- logs (`.log`, `.txt`)
- configs and metadata (`.json`, `.yaml`, `.yml`)
- intermediate or final outputs from experiments

Examples:
- `fit_metric/draw_geo.py` → `fit_metric/result/draw_geo/<timestamp>/`
- `fit_metric/draw_geo_orthogonal.py` → `fit_metric/result/draw_geo_orthogonal/<timestamp>/`
- `fit_metric/variational_geodesic.py` → `fit_metric/result/variational_geodesic/<timestamp>/`
- `fit_metric/train_with_geo.py` → `fit_metric/result/train_with_geo/<timestamp>/`
- `fit_metric/scripts/sft_mix_ablation.py` → `fit_metric/result/sft_mix_ablation/<timestamp>/`

Requirements:
- Each execution should create a new timestamped directory
- Files from different runs should not be mixed in the same directory
- Scripts should create the output directory automatically if it does not exist
- Result directories must be ignored by Git and must not be committed

### Scripts

- All runnable scripts should be placed under `fit_metric/scripts/`.
- When adding a new script, create the corresponding file under `fit_metric/scripts/` automatically.
- Script names should be clear, descriptive, and consistent with existing naming conventions.
- Each script should be designed so that its outputs can be stored in a dedicated result directory based on the script name.


## Project Management with `git`

- Create a commit after every change.
- Result files and model weight files must not be committed (for example: *.json, *.pth, *.log).
- Commit messages should include Co-authored-by.
- Only push after receiving confirmation from the user.
- All result directories should be ignored by Git and must not be committed.
